# theo shops — fábrica de animação (the real coin)

shorts de economia em cartoon, produzidos por um pipeline de apis.
este projeto não tem relação com o P.1 / pasta AntiGravity.

## pastas
- docs/        pipeline, decisões e handoff entre claude e antigravity
- personagem/  imagem de referência e ficha do personagem
- roteiros/    um arquivo por short, dividido em cenas
- audio/       voz (elevenlabs) e timestamps de cada short
- clipes/      clipes gerados por cena
- final/       vídeo montado, pronto pra subir
